stem: |
  Two balls roll off the edge of the same table, both moving horizontally with
  the same speed. Ball 1 has twice the mass of ball 2, and before reaching the
  table it rolled down a much longer ramp. Air resistance is negligible. Which
  ball lands farther from the table?
choices:
  A: 'Neither; both leave from the same height with the same velocity, so they land the same distance away'
  B: 'Ball 1, because its greater mass gives it more momentum'
  C: 'Ball 2, because a lighter ball falls more slowly and stays in the air longer'
  D: 'Ball 1, because it rolled farther on its ramp and so keeps moving longer'
answer: A
why_wrong:
  B: 'Momentum depends on mass, but the path of a projectile does not. With no air resistance, every object falls with the same acceleration $g$.'
  C: 'Without air resistance, light and heavy objects fall with the same acceleration, so both balls are in the air for the same time.'
  D: 'What happened before the ball left the table doesn''t matter. Once it is in the air, only its launch velocity and the height decide where it lands.'
---

Once a ball leaves the table, its motion depends only on its launch velocity and the height it falls from. Mass and history don't enter.

**Vertically,** both balls start with no vertical velocity and fall the same height with the same acceleration $g$, so they are in the air for the same time $t$.

**Horizontally,** nothing changes their horizontal velocity, so each goes $x = v t$. Same $v$, same $t$: same distance.
