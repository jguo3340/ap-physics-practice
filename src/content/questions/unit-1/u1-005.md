stem: |
  At the same instant, ball X rolls off the edge of a table at 2 m/s and an
  identical ball Y is released from rest at the same height. Air resistance is
  negligible. Which ball hits the floor first?
choices:
  A: 'Both at the same time, because both start with zero vertical velocity and fall with the same acceleration'
  B: 'Ball X, because it has the greater speed'
  C: 'Ball Y, because its path to the floor is shorter'
  D: 'It depends on the height of the table'
answer: A
why_wrong:
  B: 'The extra speed is horizontal, and horizontal motion does not change how fast a ball falls.'
  C: 'The length of the path does not set the time. Only the vertical motion does, and it is the same for both balls.'
  D: 'A taller table makes both falls take longer, but the two balls still take the same time as each other.'
---

Treat the horizontal and vertical motions separately. Vertically, both balls start with $v_{0y} = 0$ and accelerate downward at $g$, so both follow

$$
\Delta y = \tfrac12 g t^2
$$

and take the same time to fall the same height. Ball X's 2 m/s only carries it sideways: it lands farther from the table, at the same moment as ball Y.
