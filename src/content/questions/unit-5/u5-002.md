stem: |
  A student hangs different masses from a string wrapped around a pulley that
  turns on a horizontal axle. There is considerable friction in the axle. For
  each mass, the student measures the pulley's angular acceleration $\alpha$
  and the torque $\tau$ the string exerts on the pulley, then graphs $\alpha$ as
  a function of $\tau$. Which of the following best describes the graph?
choices:
  A: 'A straight line through the origin'
  B: 'A straight line that crosses the $\alpha$ axis above zero'
  C: 'A straight line that crosses the $\tau$ axis at a positive torque'
  D: 'A straight line that slopes downward'
answer: C
why_wrong:
  A: 'That would be true without friction. Friction in the axle opposes the rotation, so a small torque from the string gives no angular acceleration at all.'
  B: 'That would mean the pulley speeds up with no torque from the string, as if friction helped it turn. Friction works against the rotation.'
  D: 'More torque from the string gives more angular acceleration, so the line must slope upward.'
---

Apply Newton's second law for rotation, including the friction torque $\tau_f$, which opposes the turning:

$$
\alpha = \frac{\tau - \tau_f}{I} = \frac{1}{I}\,\tau - \frac{\tau_f}{I}
$$

This is a straight line with slope $1/I$, shifted to the right. The angular acceleration is zero when $\tau = \tau_f$, so the line crosses the $\tau$ axis at a positive torque, equal to the friction torque. (Below that, the string can't even get the pulley turning.)
